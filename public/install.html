Установить на телефон

Butterfly работает как приложение — без App Store и без скачивания из магазинов.

iPhone / iPad — Safari

  1. Открой этот сайт именно в Safari (не в браузере внутри другого приложения).
  2. Нажми кнопку «Поделиться» — квадрат со стрелкой вверх.
  3. Пролистай вниз и выбери «На экран „Домой“».
  4. Название «Butterfly» оставь или измени → «Добавить».
  5. Открывай с иконки: приложение откроется на весь экран, без адресной строки.

Android — Chrome

  1. Открой сайт в Chrome.
  2. Нажми меню ⋮ в правом верхнем углу.
  3. Выбери «Добавить на главный экран» или «Установить приложение».
  4. Подтверди «Добавить».

Компьютер — Chrome, Edge

  1. Открой сайт в браузере.
  2. В адресной строке нажми иконку установки (монитор со стрелкой) или меню → «Установить Butterfly».
