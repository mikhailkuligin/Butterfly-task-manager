# Поддержка

- **Ошибки и предложения** — через GitHub Issues (шаблоны в `.github/ISSUE_TEMPLATE`).
- **Уязвимости** — только через GitHub Security Advisories, не в публичный issue (см. [SECURITY.md](SECURITY.md)).
- **Документация** — [README.md](README.md), [DEPLOY-REG-RU.md](DEPLOY-REG-RU.md), [QA-ОТЧЕТ.md](QA-ОТЧЕТ.md).

Проект учебный; поддержка оказывается по возможности, без SLA.
